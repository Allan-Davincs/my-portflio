## Features

- **SplashCoder Screen** — Terminal-style boot animation on first visit
- **Dark / Light Theme** — Obsidian charcoal dark mode + clean light mode
- **Left Sidebar Navigation** — API-docs style routing (`GET /introduction`, `CORE_SYSTEMS /jenga-online`, etc.)
- **Performance Metrics Badges** — Throughput, language, latency per project
- **Sub-Navigation Tabs** — Overview, Architecture, API Reference per project
- **Syntax-Highlighted Code Blocks** — Shiki highlighting with copy-to-clipboard

## Projects Documented

1. Jenga Online E-Commerce
2. Flex AI (WhatsApp automation)
3. VeloRoute Proxy (Go load balancer)
4. NEXA AI (Enterprise RAG)
5. UniTranslate
6. Terminal Portfolio

## Stack

- Next.js 16 + TypeScript
- Tailwind CSS v4
- shadcn-style Radix UI (Tabs)
- Shiki syntax highlighting
- Framer Motion
- next-themes

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
